## OSRBOT Link 1.0.0

Local USB keyboard and mouse control, optional video capture, trusted-LAN browser access and network sharing on supported systems.

- Native OSRBOT HID device selection, recovery and keyboard/mouse forwarding.
- Computer absolute mode and Android relative mode, with a consistent Shift+Esc exit.
- Optional capture-card video, device refresh, capture parameters, fit/fill/original/stretch and fullscreen.
- Compact draggable fullscreen toolbar and consistent menus and settings.
- Screenshots, recording and GIF export with timestamped filenames.
- ASCII command paste with preview, limits, speed selection, Stop and configurable Ctrl+Alt+V quick paste.
- LAN/WebRTC video with one-time pairing, explicit remote permission and concurrent local input.
- Independent network sharing, existing sharing-state recognition and target-side reachability display on supported systems.
- Chinese and English UI, system-following appearance and optional local diagnostic logs.

LAN streaming keeps the selected quality profile during idle periods; actual performance still depends on hardware and the network.
