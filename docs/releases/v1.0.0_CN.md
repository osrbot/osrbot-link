# OSRBOT Link 1.0.0

[English](v1.0.0.md) · [产品说明](../../README_CN.md) · [安装指南](../user-guide_CN.md#安装)

**USB 键鼠共享、视频采集与局域网控制。**

OSRBOT Link 1.0 支持本地 USB 键鼠控制、可选采集卡画面、局域网浏览器访问，以及在支持的主控系统上使用网络共享。

## 更新重点

- 原生 HID 选择与重置，电脑绝对模式和安卓相对模式。
- 视频采集独立使用，手动选择设备和支持的采集参数，提供多种缩放方式。
- 紧凑设置、跟随系统外观与可拖动全屏工具栏。
- 截图、录屏、GIF 导出的文件名自动包含时间戳。
- ASCII 命令粘贴支持预览、停止，以及可配置的 Ctrl+Alt+V 快捷粘贴。
- 局域网 WebRTC 访问使用一次性配对码，并提供明确的“允许控制 / 关闭控制”。
- 允许远程输入时本机仍可操作，关闭设置窗口不会撤销远程权限。
- 局域网串流在空闲期间保持所选画质模式。
- 网络共享独立运行，可识别已有共享状态并显示被控端侧 IP 与连通性。
- 中英文界面和按需开启的本地诊断日志。

## 下载选择

发布附件包含 Windows x64 便携版与安装版、macOS Apple Silicon 与 Intel DMG、Ubuntu x86_64 DEB 与 AppImage。Ubuntu 推荐使用 DEB。

## 安装前请注意

- Windows 需要 WebView2，当前包尚无 Authenticode 数字签名。
- macOS 需要 12 或以上，当前为本地临时签名、未经过 Apple 公证；互联网共享需在系统设置中手动开启。
- 同一套 Ubuntu 包适用于 22.04、24.04、26.04，包含专用 WebKitGTK 4.1 和 GStreamer 运行库。AppImage 以普通桌面用户运行，不要使用 sudo。
- 局域网服务仅用于可信网络，不要将 HTTP 监听端口开放到公网。
- 粘贴是 ASCII 键盘输入，不是文件传输或中文剪贴板同步。
- 本次仅发布客户端，不包含固件。
