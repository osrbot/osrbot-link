# OSRBOT Link 1.0.0

[简体中文](v1.0.0_CN.md) · [Product overview](../../README.md) · [Installation guide](../user-guide.md#installation)

**USB keyboard and mouse sharing, video capture and LAN control.**

OSRBOT Link 1.0 supports local USB keyboard and mouse control, optional capture-card video, LAN browser access and network sharing on supported host systems.

## Highlights

- Native HID selection and reset, with Computer absolute mode and Android relative mode.
- Independent video capture, manual device selection, supported capture parameters and flexible scaling.
- Compact settings, system-following appearance and a draggable fullscreen toolbar.
- Screenshots, video and GIF exports with timestamped filenames.
- ASCII command paste with preview, a Stop action and configurable Ctrl+Alt+V quick paste.
- LAN/WebRTC access with one-time pairing and an explicit Allow Control / Stop Control switch.
- Local input remains usable while remote input is permitted. Closing settings does not revoke that permission.
- LAN streaming keeps the selected quality profile during idle periods.
- Independent network sharing with existing-state detection and target-side address/reachability feedback.
- Chinese / English interface and optional local diagnostic logs.

## Fixes in the current download

- Capture exports are saved in order so overlapping saves do not discard recordings.
- Linux can recognize and disable active network sharing after the Internet connection is lost or the route changes.
- LAN browser control preserves small wheel and touchpad scroll movements.
- Additional keys are forwarded, including Num Lock, the context-menu key and F13-F24.

## Downloads

Choose Windows x64 portable or installer, macOS Apple Silicon or Intel DMG, or Ubuntu x86_64 DEB / AppImage from the release assets. The DEB is recommended on Ubuntu.

## Before installing

- Windows requires WebView2. These binaries are not Authenticode signed.
- macOS requires version 12 or later. The application is ad-hoc signed, not Apple notarized. Internet Sharing on macOS is configured manually.
- The same Ubuntu packages support 22.04, 24.04 and 26.04 and include a private WebKitGTK 4.1/GStreamer runtime. Run AppImage as the normal desktop user, without sudo.
- LAN access is for trusted networks only. Do not expose its HTTP listener to the public Internet.
- Paste is ASCII keyboard input, not file transfer or Chinese clipboard synchronization.
- This release contains desktop clients only; no firmware is included.
