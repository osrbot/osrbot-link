# OSRBOT Link 使用指南

[English](user-guide.md) · [产品说明](../README_CN.md)

## 安装

从[官方发布页](https://github.com/osrbot/osrbot-link/releases)下载对应客户端。确认主控端的系统与处理器类型；`SHA256SUMS.txt` 提供校验值和准确文件大小。完整接线和操作说明见[中文产品手册](manual/OSRBOT_Link_Product_Manual_CN_v1.0.pdf)。

### Windows

需要 Windows 10/11 x64 和 Microsoft Edge WebView2 Runtime。便携版直接打开，安装版会创建快捷方式。当前包没有 Authenticode 数字签名，系统可能出现信誉提示。先核对来源与校验值，再决定是否允许运行，不要全局关闭杀毒软件。只有修改互联网共享需要管理员权限。

### macOS

按处理器选择 Apple Silicon 或 Intel，打开 DMG，将 **OSRBOT Link.app** 拖入“应用程序”。需要 macOS 12 或以上。当前包为本地临时签名，尚未经过 Apple Developer ID 公证。若被拦截，请确认来源后，使用系统提供的“隐私与安全性 → 仍要打开”等针对单一应用的方式；若提示损坏或校验不符，请停止并联系支持，不要全局关闭 Gatekeeper。

视频采集需要摄像头权限。原生系统按键转发另需辅助功能权限，未授权时部分按键退回普通窗口输入。macOS 互联网共享需在系统设置中手动配置。

### Ubuntu

同一套 x86_64 DEB 和 AppImage 适用于 Ubuntu 22.04、24.04、26.04，已包含专用 WebKitGTK 4.1 和 GStreamer 运行库，不需要另行安装 WebKitGTK 4.0。系统仍需提供正常的桌面、显卡驱动、USB 和会话服务。

推荐通过系统软件包管理器安装 DEB，以便处理依赖并安装 OSRBOT udev 权限规则。安装后，在已登录的本机桌面会话中重新插拔共享器 USB。

AppImage 运行前设置可执行权限，然后以普通桌面用户打开，不要使用 `sudo`。缺少 FUSE 时优先使用 DEB；也可以给 AppImage 加上 `--appimage-extract` 参数解包，再运行 `squashfs-root/AppRun`。设置中的 Linux HID 权限修复只申请安装 OSRBOT 专用规则，不会放开所有 HID 设备。

网络共享还需要 NetworkManager、iproute2 和 PolicyKit。原生系统按键捕获基于 X11；Wayland 下部分系统保留按键可能受限。

## 本地控制

1. 手动选择 OSRBOT HID 设备并连接。刷新列表不会自动连接。
2. 按需选择采集设备、分辨率和 FPS，并开始视频。更改参数前先停止视频。
3. 电脑模式为绝对定位；安卓模式为相对输入，需要主动点击后捕获。
4. 点击工作区共享输入。**Shift+Esc** 释放本机按键和鼠标按钮，并退出全屏。可在“输入与快捷键”中启用右 Ctrl 退出控制。

绝对鼠标按实际显示画面映射，不包含周围黑边。适应显示完整画面，填满可能裁剪画面，原始尺寸保留源尺寸，拉伸会改变宽高比。

## 粘贴与录制

粘贴通过模拟键盘输入实现，结果受被控端键盘布局影响。目前支持 ASCII，不支持中文、文件传输或双向剪贴板同步。预览内容后再发送，可随时停止；预览发送上限为 1,200 字符。可配置的 **Ctrl+Alt+V** 快捷键直接发送不超过 256 字符的单行可打印文本，不自动补回车；更长或多行内容转到预览。首次连接新目标时，先用无风险的短文本验证。

截图、录屏和 GIF 的默认文件名包含时间戳。停止视频也会停止正在进行的录制。保存位置由你在保存窗口中选择。

## 局域网控制

局域网控制独立于网络共享。选择主控端可访问的本机 IP，开启服务，将显示的地址交给同一可信局域网中的另一台电脑。浏览器输入新的四位数字配对码后连接。配对码有效期为两分钟，只能连接一次；重新连接或重新打开页面需要新码。

主控端点**允许控制**后开放远程输入；**关闭控制**只关闭远程输入，观看和本机控制仍可继续。关闭设置窗口或生成新码不会撤销这一权限。多个浏览器可观看，但同一时间只有一个远程浏览器拥有控制权。本机与远程操作同时进行时，由使用者自行协调。

切换全屏和缩放不需要断开连接。串流在空闲期间保持所选画质模式。查看画面前需在主控端开始视频；没有采集卡时仍可共享键鼠。

只在预期的私有网络上允许防火墙访问。HTTP 页面、配对和信令无法抵御同网段攻击，不要通过端口转发暴露到公网。

## 网络共享

选择主控端的外网网卡，以及连接被控端的以太网卡。两者都是**主控电脑上的网卡**，“被控端网卡”是指主控端朝向被控端的那张网卡。已存在的系统共享会直接读取并显示，无需重复开启。扫描网卡不要求先插网线。

Windows 使用 ICS，修改时需要管理员权限；Ubuntu 使用 NetworkManager 与系统授权；macOS 需手动设置。这些操作不会断开 HID 或停止视频。

检测到被控端侧地址后，Ping 结果仅说明主控端到该设备的连通性，不代表设备已能访问外网，也不能确认它就是 USB 连接的同一台设备。该网段存在多台设备时，请自行核对目标地址。

## 常见排查

- **画面延迟**：USB 键鼠与画面是独立链路。画面反馈主要受采集卡、USB 传输、处理与显示影响；局域网访问还受网络和编解码影响。FPS 不能单独代表端到端延迟。
- **输入失效**：先按 Shift+Esc 释放，再使用重置 HID、刷新列表并手动重连。系统无法恢复 USB 设备时，仍可能需要重新插拔。
- **视频启动失败**：检查摄像头权限、是否被其他软件占用，以及采集卡支持的分辨率与 FPS。界面会显示实际采集参数。
- **局域网连不上**：检查所选 IP、网络、防火墙及新的配对码，不需要先开启网络共享。
- **需要诊断日志**：复现问题前在设置中开启诊断日志，复现后导出。日志默认关闭，仅本地保存，不记录按键内容、剪贴板文字、画面或配对码。

反馈时请提供系统、客户端版本、硬件型号和复现步骤，联系 [OSRBOT 支持](mailto:winter@osrbot.com)。
