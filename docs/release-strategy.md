# OSRBOT Link packages

[English overview](../README.md) · [中文产品说明](../README_CN.md) · [Installation](user-guide.md#installation)

Choose the OSRBOT Link package for the operating system and processor of the host computer.

| Host | Package | Use |
| --- | --- | --- |
| Windows x64 | Portable EXE | Open directly; WebView2 is still required |
| Windows x64 | Installer EXE | Install with application shortcuts |
| macOS | Apple Silicon / Intel DMG | Choose the matching CPU; copy OSRBOT Link to Applications |
| Ubuntu x64 | DEB | Recommended; installs the scoped HID permission rule |
| Ubuntu x64 | AppImage | Run without DEB installation; system libraries and HID permissions still apply |

## 简体中文

按主控电脑的系统和处理器选择 OSRBOT Link 安装包。Windows 提供便携版和安装版；macOS 提供 Apple Silicon 和 Intel 的 DMG；Ubuntu 提供 DEB 和 AppImage，推荐 DEB。

从官方发布页下载，并核对校验值。不要为了运行应用而全局关闭系统安全机制。更多内容见[中文安装说明](user-guide_CN.md#安装)。
