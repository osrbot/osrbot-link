# Packages and editions

[Product overview](../README.md) · [中文产品说明](../README_CN.md) · [All downloads](https://github.com/osrbot/osrbot-link/releases)

## Choose an edition

- **[OSRBOT Link Lite v0.2](https://github.com/osrbot/osrbot-link/releases/tag/lite-v0.2.0):** local keyboard and mouse sharing, optional video preview, screenshots and recording. Currently marked as a preview release.
- **[OSRBOT Link Pro v0.7.0](https://github.com/osrbot/osrbot-link/releases/tag/pro-v0.7.0):** local control plus LAN browser access, network-sharing assistance and extended diagnostics. Network-sharing support depends on the host operating system.

Lite and Pro have separate version numbers. Compare features and system requirements, not the version number alone.

## Choose a package

| Platform | Package | When to choose it |
| --- | --- | --- |
| Windows x64 | Portable `.exe` | Open the client without an installation wizard; system runtime and permission requirements still apply |
| Windows x64 | Installer `.exe` | Install the client with shortcuts |
| macOS | Apple Silicon / Intel `.dmg` | Match the Mac's processor type |
| Ubuntu x64 | `.deb` | Recommended for installation and HID permission setup |
| Ubuntu x64 | `.AppImage` | Run without a DEB installation; runtime libraries and HID permissions are still required |

Read the release's installation notes before downloading. GitHub's automatically generated **Source code** archives contain this documentation repository, not an installable client. Download a named OSRBOT client package instead.

## Safe installation

Download from this official repository. Do not disable operating-system security globally to open an application. If the system blocks a package, confirm its source and follow the edition's installation notes or contact OSRBOT. Where a checksum file is supplied, it can be used to check the downloaded file's integrity.
