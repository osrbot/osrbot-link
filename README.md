# OSRBOT Link Keyboard and Mouse Sharing Device

[简体中文](README_CN.md) · **[Download](https://github.com/osrbot/osrbot-link/releases)**

OSRBOT Link lets you use your computer's keyboard and mouse to operate another computer, development board or industrial device for debugging, maintenance and teaching.

Run the software on the control computer only. The controlled device needs no software installation: it sees a standard USB keyboard and mouse. Add a capture card to view its screen in the same window.

<p><a href="docs/images/product-hero-white.png"><img src="docs/images/product-hero-white.png" alt="OSRBOT Link Keyboard and Mouse Sharing Device on a white background" width="480"></a></p>

## Core capabilities

- **Keyboard and mouse control:** A direct USB connection for low-latency input.
- **Video and recording:** Use a capture card to view the screen, adjust scaling or fullscreen, and save screenshots, recordings and GIFs.
- **Quick input:** Paste ASCII commands, customize shortcuts, and choose your preferred language and appearance.
- **Networking and collaboration:** Share a network connection over Ethernet, or view and help operate the device through a browser on the same trusted LAN.

## Connections

Plug the sharing device into the control computer, then connect the controlled device with the included USB-A to USB-A data cable. Keyboard and mouse control works without a capture card; add one when you need video. Network sharing uses a separate Ethernet cable.

<p><a href="docs/images/connection-control-en.png"><img src="docs/images/connection-control-en.png" alt="Keyboard and mouse connection: control computer to OSRBOT Link, then port 4 to the controlled device using the included data cable" width="780"></a></p>

Image quality and frame rate depend on the capture card. Visual delay mainly comes from capture, processing and display; LAN access also depends on network conditions.
