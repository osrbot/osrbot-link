# OSRBOT Link

OSRBOT Link 是面向 OSRBOT 键盘鼠标共享器 2.0 的跨平台桌面客户端。它可以把主控电脑的键盘、鼠标输入通过 OSRBOT 共享器转发到被控端设备，也可以配合 USB 采集卡提供画面预览、全屏控制、截图、录屏和 GIF 录制能力。

![OSRBOT Link workflow](docs/images/osrbot-link-overview.svg)

## 项目定位

OSRBOT Link 面向机器人调试、嵌入式设备维护、无头主机管理、多设备桌面控制、实验室设备运维等场景。用户可以在一台主控电脑上集中完成键盘、鼠标和可选视频画面的控制，减少频繁切换外设、显示器和采集软件的成本。

客户端支持两种使用方式：

- 纯键鼠共享：被控端本身有屏幕，或用户可以直接看到被控端画面时，只连接 OSRBOT 键盘鼠标共享器即可。
- 视频预览控制：需要在主控端查看被控端画面时，同时接入 USB 采集卡，客户端会显示采集画面并在画面区域内完成控制。

被控端可以是 Windows、macOS、Ubuntu 等桌面系统，也可以是安卓手机和平板。

## 主要功能

- OSRBOT HID 键盘、鼠标输入转发。
- 电脑/安卓两种目标模式。
- 电脑模式默认使用绝对鼠标模式，适合桌面系统。
- 安卓模式使用相对鼠标模式，适合安卓手机和平板。
- 支持右 Ctrl 退出控制模式。
- 支持 Shift+Esc 同时退出全屏和控制模式。
- 支持传统滚轮方向和滚轮方向设置。
- 支持 USB 采集卡视频预览。
- 支持无采集卡的纯键鼠共享模式。
- 支持自定义采集分辨率和实际采集参数显示。
- 支持自适应、填满、原始三种画面缩放模式。
- 支持全屏浮动工具栏自动隐藏、手动隐藏和手动显示。
- 支持截图、视频录制和 GIF 录制。
- 支持终端命令粘贴，通过 HID 逐字符输入 ASCII 命令文本。
- 支持粘贴长度限制、发送前预览和发送中停止。
- 支持手动切换被控端显示输出。
- 支持明亮/深色皮肤切换。
- 支持中文和英文界面。

## 目标设备模式

### 电脑模式

电脑模式是默认模式，使用绝对鼠标坐标。该模式适合 Windows、macOS、Ubuntu 等桌面系统，鼠标在采集画面区域内控制被控端；非全屏状态下，鼠标可以正常移出客户端窗口。

### 安卓模式

安卓模式使用相对鼠标移动，适合安卓手机和平板的外接鼠标场景。进入相对控制后，可以使用右 Ctrl 退出控制模式。

## 全屏与画面缩放

全屏模式提供三种画面缩放方式：

- 自适应：保持画面比例，尽量完整显示采集画面。
- 填满：保持比例并放大填充窗口，可能裁切边缘。
- 原始：按采集画面原始尺寸显示。

全屏浮动工具栏会在不使用时隐藏。隐藏后需要点击“显示工具栏”按钮重新唤出，避免在控制被控端时误触遮挡。

## 命令粘贴

命令粘贴用于把主控端剪贴板中的终端命令发送到被控端。当前实现基于 HID 键盘逐字符输入，适合英文命令、数字、路径和常见 shell 符号。

当前限制：

- 仅支持 ASCII 文本。
- 不支持中文、图片、文件或完整剪贴板同步。
- 文本长度有限制，发送前可预览，发送过程中可以手动停止。

完整剪贴板同步属于后续能力，需要被控端 Agent 或额外数据通道配合。

## 系统支持

OSRBOT Link 面向常见桌面平台提供客户端：

- macOS
- Windows
- Ubuntu Linux

不同系统对 HID 设备、输入监听、视频采集和应用权限的要求不同。首次使用时，可能需要根据系统提示授予输入监听、辅助功能、摄像头或 HID 设备访问权限。

## 硬件

OSRBOT Link 配套 OSRBOT 键盘鼠标共享器 2.0 使用。硬件参数、连接方式和使用注意事项，请以 OSRBOT 官方产品说明书为准。

如需购买 OSRBOT 键盘鼠标共享器硬件，请联系 OSRBOT。

## 技术栈

- HTML / CSS / JavaScript
- Chromium MediaDevices API
- node-hid / HIDAPI
