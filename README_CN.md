# OSRBOT Link 键盘鼠标共享器

[English](README.md) · **[软件下载](https://github.com/osrbot/osrbot-link/releases)**

OSRBOT Link 让你用自己电脑的键盘和鼠标，操作另一台电脑、开发板或工控设备，方便调试、维护和教学演示。

软件只需在主控端运行，被控端免安装，就像接入一套普通的 USB 键盘鼠标。搭配采集卡，还能在同一窗口查看被控端画面。

## 核心能力

- **键鼠控制**：USB 直接连接，低延迟操作被控端。
- **画面与记录**：搭配采集卡查看画面、缩放或全屏，保存截图、录屏和 GIF。
- **快捷输入**：粘贴英文命令，自定义快捷键，按习惯选择语言和界面外观。
- **网络与协作**：通过以太网为被控端共享网络；同一可信局域网内，可通过浏览器查看画面和协助操作。

## 连接方式

将共享器插入主控端，用随附的 USB-A 对 USB-A 数据线连接被控端。只需要键鼠控制时，无需采集卡；需要画面时再接入采集卡。网络共享另接以太网线。

<p><a href="docs/images/connection-control-cn.png"><img src="docs/images/connection-control-cn.png" alt="键鼠连接：主控端连接 OSRBOT Link 共享器，通过随附数据线从接口 4 连接被控端" width="780"></a></p>

画质和帧率由采集卡决定；画面延迟主要来自采集、处理与显示，局域网访问还受网络条件影响。
