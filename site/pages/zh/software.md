# 软件功能与操作

从键鼠控制、画面预览到命令输入与过程记录，在同一个软件里完成设备调试。

<figure class="software-overview"><img src="/manual/software-overview-guide.png" alt="软件主界面：顶部菜单、设备栏、画面与控制工作区" loading="lazy"><figcaption>软件主界面与功能位置</figcaption></figure>

<dl class="guide-definitions"><div><dt>顶部菜单</dt><dd>调整屏幕显示、发送控制指令、采集画面，进入设置与网络功能。</dd></div><div><dt>左侧设备栏</dt><dd>选择并连接共享器与采集卡，查看连接状态和实际采集参数。</dd></div><div><dt>画面与控制工作区</dt><dd>查看被控端画面，点击后开始键鼠操作；隐藏设备栏可扩大显示空间。</dd></div></dl>

## 操作电脑，也能切换安卓模式 {#control-feature}

使用主控端的键盘和鼠标完成被控端操作，可按设备类型切换鼠标模式。

1.  按“下载与开始”中的首次使用流程连接 HID，点击工作区进入控制。
2.  在“控制”菜单选择<strong>电脑</strong>或<strong>安卓</strong>：电脑模式使用绝对鼠标定位；安卓模式使用相对鼠标移动。
3.  需要系统组合键时，在“控制”菜单选择 <kbd>Ctrl+Alt+Del</kbd>。部分系统保留快捷键受主控端平台限制。
4.  按 <kbd>Shift+Esc</kbd> 释放控制；在“键鼠共享”中点击“断开”可结束 HID 连接。

打开设置、切换模式或转到其他窗口时，本地控制会暂停。返回后点击工作区继续；右 Ctrl 释放控制可在设置中额外启用。

## 按任务调整显示方式 {#video-feature}

检查细节时看原始尺寸，连续操作时适应窗口，也可以进入全屏。

1.  选择采集卡，在“采集参数”中设置分辨率与帧率，再点击“开始视频”。需要时可添加自定义分辨率。
2.  通过“屏幕”菜单选择显示模式或进入全屏。全屏工具栏可拖动、隐藏或重新显示，提供缩放、模式、粘贴、截图、录屏与 GIF 入口。
3.  更换采集设备或参数前先停止视频；实际分辨率与帧率以状态栏为准。

<dl class="display-modes"><div><dt>适应窗口</dt><dd>保留比例，显示完整画面。</dd></div><div><dt>填满窗口</dt><dd>保留比例，可能裁去边缘。</dd></div><div><dt>原始尺寸</dt><dd>按原始像素尺寸显示。</dd></div><div><dt>拉伸窗口</dt><dd>填满工作区，比例可能改变。</dd></div></dl>

预览、分辨率与帧率取决于所选采集卡及输入信号；填写自定义参数不会改变采集卡本身的能力。

## 截图、录屏与 GIF {#capture-feature}

保存设备画面与操作过程，用于调试反馈、教学演示和问题沟通。

先开启视频，再使用“采集”菜单或全屏工具栏。

<table><thead><tr><th scope="col">工具</th><th scope="col">操作与保存</th></tr></thead><tbody><tr><th scope="row">截图</th><td>点击“截图”，选择位置，保存当前采集画面。</td></tr><tr><th scope="row">录屏</th><td>点击“录屏”开始，点击“停止录屏”结束并保存。单段达到 256 MiB 时自动停止并保存，可继续录制下一段。</td></tr><tr><th scope="row">GIF</th><td>点击“GIF”录制短片，停止后保存；单次最长约 10 秒。</td></tr><tr><th scope="row">自定义水印</th><td>在“设置 → 采集与水印”填写名称，追加到 OSRBOT Link 水印中。</td></tr></tbody></table>

记录内容来自采集卡画面。停止视频会结束录制，保存完成后再关闭软件或拔下设备。

## 把命令发送到被控端 {#paste-feature}

通过粘贴助手，将主控端的英文命令转换为键盘输入，减少手动输入。

<figure class="software-dialog"><img src="/manual/software-paste-guide.png" alt="粘贴助手：命令输入、发送选项、速度与控制按钮" loading="lazy"><figcaption>粘贴助手：输入与发送</figcaption></figure>

1.  连接 HID，将被控端的输入焦点放到终端或需要输入的文本框。
2.  进入“控制 → 粘贴助手”，检查剪贴板内容，或直接输入命令。
3.  选择快、标准或慢速，确认是否勾选“发送后按 Enter”。
4.  点击“发送粘贴”，等待完成；需要中断时点击“停止发送”。

### 快捷粘贴：Ctrl + Alt + V

本地控制时可直接发送不超过 256 字符的单行可打印 ASCII 文本，不自动按 Enter；较长或多行内容进入预览后再发送。

粘贴助手最多支持 1,200 个 ASCII 字符，不支持中文或文件传输。普通 Ctrl+V 只向被控端发送快捷键，不会同步两台设备的剪贴板。

## 按习惯设置界面与输入 {#settings-feature}

界面与输入偏好保存在主控端，支持中英文，浅色、深色或跟随系统外观。

<figure class="software-dialog"><img src="/manual/software-settings-guide.png" alt="设置操作图：1 切换功能分页，2 设置语言与外观，3 启用并导出诊断日志" loading="lazy"><figcaption>设置：功能分页与常用选项</figcaption></figure>

<dl class="settings-list"><div><dt>输入与快捷键</dt><dd>选择电脑或安卓模式、传统或自然滚动，设置右 Ctrl 释放控制、鼠标位置提示及快捷粘贴。</dd></div><div><dt>采集与水印</dt><dd>设置截图、录屏和 GIF 的自定义水印名称。</dd></div><div><dt>窗口布局与应用信息</dt><dd>通过“设备”或“屏幕”菜单显示、隐藏设备栏；通过“关于”查看应用信息与第三方许可。</dd></div></dl>

更改偏好不会自动连接设备。需要重新使用共享器或采集卡时，手动选择并连接。

## 恢复设备，保留排查信息 {#recovery-feature}

遇到异常时，分别处理 HID、权限和日志，方便继续操作或联系支持。

<dl class="settings-list"><div><dt>重置 HID</dt><dd>键鼠无响应时，点击左侧“重置 HID”，等待完成后刷新列表、选择设备并重新连接。重置不会自动恢复控制，也不会主动停止视频或录制。</dd></div><div><dt>修复 Linux HID 权限</dt><dd>进入“设置 → 输入与快捷键”，选择“修复 Linux HID 权限”，按系统提示授权后重新扫描，必要时重新插拔共享器。</dd></div><div><dt>导出诊断日志</dt><dd>在“设置 → 通用”开启诊断日志，复现问题后点击“导出”，与错误提示和操作步骤一起提供给支持人员。可点击“清空”删除本次日志。</dd></div></dl>

诊断日志仅记录本次运行的状态，不记录键盘内容、剪贴板或画面，也不会自动上传。
