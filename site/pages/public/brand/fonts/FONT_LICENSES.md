The current wordmark is supplied as outlines, with adjusted width and spacing. Use that artwork directly. Font files are unmodified vendor distributions; do not rename or modify distributed fonts without checking the OFL conditions and reserved font names.

Install the fonts in the editor's operating system before editing. If a renderer uses an isolated user profile, make sure it can still access the installed fonts. Confirm that Chinese characters display and that PDF exports contain the intended font families. The quotation and DOCX previews were rendered with the included families available.
